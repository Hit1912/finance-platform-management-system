# 💰 Finance Platform Management System

A **Finance Platform Management System** is a web-based application designed to help users **manage personal finances, track expenses, monitor income, and analyze financial data** in an organized way.

This project is built using the **MERN Stack** and provides a **simple, secure, and user-friendly platform** for managing financial activities.

---

# 📌 Project Overview

The **Finance Platform Management System** helps users manage their financial activities efficiently.

Users can:

* Track **income and expenses**
* Manage **financial records**
* View **transaction history**
* Analyze **spending patterns**
* Maintain better **financial control**

---

# 🚀 Features

## 1️⃣ User Authentication

* Secure user **registration and login**
* **JWT based authentication**
* Protected routes

## 2️⃣ Income Management

* Add income records
* Categorize income sources
* View total income statistics

## 3️⃣ Expense Tracking

* Add daily expenses
* Categorize expenses (Food, Travel, Shopping, etc.)
* Edit or delete expense records

## 4️⃣ Financial Dashboard

* Overview of **total income**
* Overview of **total expenses**
* Remaining **balance**
* Quick financial insights

## 5️⃣ Transaction History

* View all transactions
* Filter by **date or category**
* Detailed financial logs
